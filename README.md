# Workshops — Build a Conversational Agent

Dépôt compagnon des ateliers du livre *De l'assistant à l'agent : anatomie d'un agent conversationnel*.

Ce dépôt fournit l'environnement et les tests de bout en bout pour réaliser les ateliers. Il ne contient pas le code de l'agent : chaque étudiant construit le sien, à partir d'une coquille minimale.

La licence n'est pas encore fixée ; aucun fichier `LICENSE` n'est publié pour le moment.

Le contenu détaillé (applications de test, proxy, cadre de test, guides) arrive dans une branche de travail.
