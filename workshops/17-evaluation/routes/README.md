# Jeu de parcours d'évaluation

Les parcours officiels du chapitre 17, lorsqu'ils seront publiés ici, ne doivent
pas être modifiés par l'outil de l'atelier 19. Une part réservée n'est pas
distribuée dans ce dépôt public et doit rester hors d'atteinte du mode local.

Le fichier `somme-parcours.sha256` permet de vérifier l'intégrité de ce dossier.
